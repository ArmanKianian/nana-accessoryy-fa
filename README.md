# نانا اکسسوری شاپ ✿

فروشگاه استاتیک فارسی برای پیج اینستاگرام **@nana.accessoryy**؛ ساخته‌شده با Astro و Tailwind CSS و آماده‌ی انتشار روی GitHub Pages.

## قبل از انتشار

1. آدرس سایت از قبل برای حساب GitHub تو تنظیم شده: `https://armankianian.github.io/nana-accessoryy-fa/`. برای انتشار با همین نام مخزن، نیازی به تغییر آدرس نیست.
2. اگر اسم مخزن `nana-accessoryy-fa` است، مقدار `base: "/nana-accessoryy-fa"` را نگه دار. اگر اسم دیگری انتخاب کردی، `base` و مسیر لینک صفحه 404 را هم تغییر بده.
3. اگر بعداً نام کاربری یا نام مخزن را عوض کردی، آدرس سایت را در `astro.config.mjs`، `src/layouts/BaseLayout.astro`، `src/pages/index.astro`، `src/pages/404.astro` و `public/robots.txt` به‌روز کن.
4. تصاویر فعلی محصولات فقط تصویرهای گرافیکی نمونه هستند. قبل از انتشار، عکس واقعی محصولات، نام، قیمت و توضیحات دقیق را وارد کن.
5. آدرس اینستاگرام، روش سفارش، اطلاعات ارسال و هر ادعای مربوط به محصول را بررسی کن.

## اجرای محلی

```bash
npm install
npm run dev
```

برای ساخت نسخه انتشار:

```bash
npm run build
npm run preview
```

خروجی آماده انتشار در پوشه `dist/` قرار می‌گیرد.

## انتشار روی GitHub Pages

1. یک مخزن با نام `nana-accessoryy-fa` بساز و فایل‌های پروژه را روی شاخه `main` بفرست.
2. در **Settings → Pages**، منبع انتشار را روی **GitHub Actions** قرار بده.
3. گردش‌کار موجود در `.github/workflows/deploy.yml` به‌صورت خودکار پروژه را build و منتشر می‌کند.
4. نتیجه را از بخش **Actions** مخزن بررسی کن.

## امکانات SEO

- عنوان و توضیحات متای فارسی و متناسب با فروشگاه
- آدرس canonical و دامنه GitHub Pages تنظیم‌شده برای حساب `ArmanKianian`
- زبان صفحه `fa` و جهت راست‌به‌چپ `rtl`
- لینک canonical و متادیتای Open Graph و Twitter
- داده ساختاریافته `Store` با پیوند به اینستاگرام
- sitemap خودکار و `robots.txt`
- HTML استاتیک، هدینگ‌های معنایی، لینک‌های قابل دسترس و صفحه 404

## نکته مهم درباره SEO

هیچ تگ یا قالبی رتبه اول گوگل را تضمین نمی‌کند. برای نتیجه بهتر، عکس‌های واقعی و باکیفیت، توضیحات دقیق محصولات، اطلاعات واقعی قیمت و ارسال و یک دامنه اختصاصی کمک زیادی می‌کنند. بعد از انتشار، سایت را در Google Search Console ثبت کن و sitemap را ارسال کن.

## آرشیو RAR

اگر ابزار `rar` روی لینوکس نصب است، از پوشه‌ی حاوی پروژه اجرا کن:

```bash
rar a nana-accessoryy-fa.rar nana-accessoryy-fa/
```

اگر `rar` نصب نیست، فایل ZIP ارائه‌شده را می‌توان با Archive Manager اوبونتو استخراج کرد.
